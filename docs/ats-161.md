# ATS 1.61 layout (amtrucks.exe), static RE

Reference: ETS2 1.60 `eurotrucks2.exe` (image base 0x140000000 in both). Method: same functions located in both exes
(chooser by pattern, update = its caller, vtable slots, pedal fn, setter fn) and diffed instruction by instruction.
[V] = seen in the disassembly of both exes, [I] = inferred. Nothing was run. Discovery check: `tools/check_suite.py`.

## Result
All patterns hit exactly as on 1.60 (window 1, chooser 1, torque check 1, 2 chooser call sites in the update,
1 decide site, 2 lobound calls with start-gear fn, 1 mass pattern, 1 cvar pattern, 2 gps hits that agree).
ATS 1.61 addresses: update `0x1409e5ed0`, chooser `0x1409e6930`, window fn `0x140626b40`, decide site `0x1409e639c`,
start fn `0x1409e74a0`, grade fn `0x140651120`, mass fn `0x1405e39a0`, base_ctrl slot `0x1436b8d70`,
cvar g_adaptive_shift `0x142d53470` (name copy checked, reader `0x1401dc850`).

## What changed vs 1.60 (all [V] unless noted)
- **Gearbox object (self) grew by 8 bytes at +0x68**: new float `self+0x68` (held/decayed throttle: `0x6263f0` stores the inner
  pedal in it, `self+0x6c` is a timer) read by the update instead of the inner pedal. Everything after shifts: target
  `0x68 -> 0x70`, kick/force `0x119 -> 0x121`, mode `0x110 -> 0x118`. `self+0x10` inner and `self+0x18` shift state unchanged.
  Do not write `self+0x68`.
- **inner (vehicle) +0x68** for gear/pedal/clutch/engine-brake (gear 0x14b0, pedal 0x148c/0x1490, clutch 0x1494, eb demand
  0x14a4, eb flag 0x14a8), **+0x50** for the handles (transmission 0x1038, engine 0x1040). `inner+0x150` (drive) unchanged.
- **engine def**: +8 up to the rpm ranges (torque 0x1c8, curve ptr 0x1d8, count 0x1e0, rpm limit 0x234, ranges 0x244..0x264,
  order brake/low/high/power as before), then +0x10 (engine-brake flag 0x270, stage cap 0x274).
- **transmission def**: shift time 0x1c8 (+8), auto_mode_name char* 0x270 (+0x18), manual_mode_name 0x290 (still +0x20 apart).
- **game_actor**: base_ctrl->game_actor 0x31b0, cruise flag 0x204, engine-brake fraction 0x3f0, gearbox ptr 0x1e30.
- The update gained an extra bool-cvar block (call `0x1401cd100`) and an extra read of `trans+0x260`: harmless for us.

## ETS2 1.61
Not verified (no 1.61 ETS2 exe here). The gearbox, vehicle and engine classes are shared engine code, so ETS2 1.61 very likely
uses the same entry (offsets are class members, not game-specific); `discover_with()`'s self-checks make a mismatch fail safe.
Differences to expect are only in game_ctrl/game_actor members (`gps +0x4128`, `0x31b0`, `0x204`, `0x3f0`, `0x1e30`): rerun
`tools/check_suite.py` on the new exe and compare those against ATS. If the 1.61 build family differs there, split the entry.
